## 新规概况

《浙江省自然科学研究系列继续教育学时登记细则（试行）》（浙科发才〔2026〕14号）于**2026年5月10日施行**，是自然科研系列（研究实习员、助理研究员、副研究员、研究员）继续教育学时管理的最新依据。

## 年度学时要求

> 自然科研专业技术人员参加继续教育每年度应达到**90学时，其中行业公需和一般公需科目合计不少于18学时，专业科目不少于60学时**。

继续教育学时要求是自然科研系列职称申报的**必备条件**，申报时须提交学时登记情况表及相关证明材料。

## 专业科目分A、B两类

### A类：学习培训途径（每个途径最多认定36学时）

| 途径 | 学时标准 |
|---|---|
| 人力社保部门批准的科技类高级研修项目 | 按实际授课时间，每天最高12学时 |
| 认可平台的专业科目在线学习 | 按课件标定学时 |
| 培训进修、专题讲座、学术研讨 | 按实际授课时间，每天最高12学时 |
| 科技特派员、"科技副总""产业教授"、对口支援服务等 | 每天8学时 |

### B类：成果折算途径（每个途径最多认定30学时）

| 成果类型 | 学时标准 |
|---|---|
| 纵向科技项目（主持） | 国家级30 / 省部级25 / 市厅级20 / 县区级10；横向项目10；其他排名按50% |
| 软课题研究、规划制定（主持） | 国家级30 / 省部级25 / 市厅级20 / 县区级15 |
| 论文（第一作者或通讯作者） | SCI/EI/国内核心每篇20；省级以上刊物每篇10；其他排名按50% |
| 著作（主编） | 每万字10学时 |
| 专利（排名第1） | 发明20 / 实用新型5 |
| 标准制定（主持） | 国家30 / 行业25 / 地方20 / 团体15 |
| 科技奖励（排名前3） | 国家级30 / 省级25 / 计划单列市级20 |
| 决策建议报告获批示（排名前3） | 国家级30 / 省部级20 / 市厅级10 |
| 在职学历（学位）教育 | 获毕业证书或学位证书30学时 |

## 申报时限（新规放宽）

- 学分申报须在**项目结束后90天之内**完成（原60天）；
- **12月份的学分申报截止日期为次年3月31日**。

## 新规三大亮点（官方解读）

1. **多元认定**：科技项目、论文、专利、标准、奖励、人才流动共享、科技咨询与管理服务等成果均纳入学时认定范围；
2. **分层分类**：专业科目分A/B两类并分别设定学时上限，鼓励长期、稳定、多途径开展继续教育；
3. **刚性执行**：学时完成情况作为职称申报必要条件，须提交学时登记情况表及证明材料。
